# Full E1 verdict structure

Issue independent verdicts:

`VISUAL-GO / CAUTION / NO-GO`

`AUDIO-GO / CAUTION / NO-GO`

`ALIGNMENT-GO / CAUTION / NO-GO`

`REPRODUCIBILITY-GO / CAUTION / NO-GO`

Then issue overall:

### STRONG GO

Visual and audio both demonstrate useful derivation evidence, temporal alignment is reliable, and multimodal use materially improves decision quality.

### CORE GO

At least one perceptual modality meets its required discrimination target and temporal provenance is sufficiently reliable.

### CAUTION

Useful capability exists but only for restricted durations/transforms/modalities, requiring narrower product claims.

### CORE NO-GO

No perceptual modality separates realistic derivatives from deliberately confusing negatives at a useful operating point,

OR

temporal alignment routinely invents false provenance intervals.

CORE NO-GO is an acceptable scientific result.
